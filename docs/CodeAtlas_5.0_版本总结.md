# CodeAtlas 计算机学习导航系统 5.0 版本总结

> 项目驱动学习平台 · 前端可演示 MVP  
> 线上地址：https://cs-learning-nav.vercel.app/  
> 技术栈：Vite 5 + React 18 + TypeScript 5 + Tailwind CSS 3 + React Router 6  
> 数据驱动：本地 TypeScript 数据文件（无后端、无数据库）

---

## 一、项目定位

CodeAtlas 是一个面向计算机相关专业学生的**系统化学习与职业发展平台**。它的核心目标不是内容堆砌，而是**知识关系组织**——把课程、知识点、工具、项目、岗位、面试问题和学习路径连接起来，帮助用户回答七个核心问题：

1. 学什么
2. 为什么学
3. 怎么学
4. 用什么工具
5. 能做什么项目
6. 对应什么就业方向
7. 面试可能怎么问

5.0 版本的核心升级在于：**从"能看导航"升级为"能按路径学习、能看课程内容、能做项目任务、能查工具、能准备岗位"的完整前端学习网站。**

### 每门课程包含

- **learningObjectives**（学习目标）：3-5 条可衡量的能力目标
- **prerequisites**（前置要求）：明确的前置知识和技能
- **chapters**（章节目录）：每章含要点总结 + 关键知识点 + 配套练习
- **practiceTasks**（实践任务）：3-5 个带验收标准的综合任务
- **recommendedResources**（推荐资源）：书籍、视频、工具
- **externalResources**（外部资源）：带 URL 的免费在线教程和练习平台
- **learningTips**（学习建议）：具体可操作的学习方法
- **units**（课程单元）：部分课程含可点击的子单元详情
- **interviewQuestions**（面试问题）：典型面试题

### 课程与课程的关联

每门课程通过 `relatedTools`、`relatedProjects`、`relatedJobs` 字段与工具、项目、岗位建立双向关联，用户可以点击跳转。

### 每个任务（TaskStep）包含

- **resources**（资源链接）：标注 `isRequired` 和 `status: verified/pending/needs_review`
- **acceptanceCriteria**（验收标准）：可量化的完成标准
- **commonMistakes**（常见错误）：部分任务含避坑指南

## 十二、用户能如何真正学习

5.0 不是只"展示有什么"，而是提供了**可执行的学习操作**：

1. **按角色入口进入**：首页根据用户身份（新生/应届生/转行者）提供不同的起步建议
2. **按路径学习**：选择一条学习路径 → 进入阶段详情 → 按检查清单逐项完成 → 做关联项目 → 准备面试
3. **按课程学习**：浏览课程 → 查看章节目录和学习目标 → 完成实践任务（含验收标准）→ 做关联项目巩固
4. **按项目练习**：选择项目 → 按任务流逐项完成 → 对照验收标准自检 → 查看关联课程补理论
5. **按岗位准备**：选择目标岗位 → 查看能力要求和学习计划 → 按能力模块逐项学习 → 准备面试重点
6. **查工具使用**：搜索工具 → 查看安装步骤 → 学习常用命令 → 查看使用场景 → 参考常见问题排错
7. **全站搜索**：输入关键词 → 跨模块查找 → 按类型筛选 → 点击高亮结果直达详情

## 十四、后续可选升级方向

以下方向供下一阶段规划参考，不属于当前 MVP 范围：

1. **内容扩充**：增加更多课程（如计算机组成、云计算、NLP）、更多项目（如微服务项目、移动端项目）
